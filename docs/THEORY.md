# The model `drvec` estimates: statements, proofs, and what they require

*Every theorem this program has been leaning on was proved for a neighbouring
model — Johansen's for the pure autoregression, Yap and Reinsel's for the VARMA
in reduced-rank form, the BVECM appendix for Phillips' triangular
representation. None of them is stated for the object `drvec` optimises over:
the vector error-correction form with an unrestricted moving average, in the
parameters `(Λ, B₂, F_i, Θ_j, Σ)`, estimated through Mauricio's transformation.
This note writes those statements down and proves them where a proof is short,
because a simulation without a theorem behind it is a stick in the dark, and
because the measurements of [HOMOLOGATION.md](HOMOLOGATION.md) §4g–§4l turned
out to be pointing at a condition nobody had written.*

Each result is labelled **[standard]** when it is a restatement of a known
theorem in this parameterisation, **[new here]** when I have not found it stated
for this model, and **[empirical]** when it is a measurement and not a theorem.

---

## 1. The model, and the set the program optimises over

Let `{Y_t}` be `M`-dimensional, `0 < r < M`, `s = M − r`. `drvec` fits

  **(1)**  `F(L) ∇Y_t = −Λ B′ Y_{t−1} + Θ(L) A_t`,

with `F(L) = I − Σ_{i=1}^{p−1} F_i L^i`, `Θ(L) = I − Σ_{j=1}^{q} Θ_j L^j`,
`A_t ~ IID(0, Σ)`, `Σ > 0`, `Λ` of full column rank `r`, and

  **(2)**  `B = [I_r ; B₂]`,  `B₂` free `s × r`,  `W_t = B′Y_t = Y_{1t} + B₂′Y_{2t}`.

Collecting terms, (1) is the VARMA `Φ(L)Y_t = Θ(L)A_t` with

  **(3)**  `Φ(L) = F(L)(1 − L) + Λ B′ L`,   so   `Φ(1) = Λ B′ = Π`, of rank `r`.

Write `Λ⊥`, `B⊥` for `M × s` matrices of full column rank with `Λ⊥′Λ = 0`,
`B⊥′B = 0`.

*Sign conventions, since they are where these comparisons usually go wrong.*
Johansen writes `∇Y_t = Π_J Y_{t−1} + Σ Γ_i ∇Y_{t−i} + ε_t` with `Π_J = αβ′`;
(1) writes `−ΛB′Y_{t−1}` and `F(L)` on the left. Hence `α = −Λ`, `β = B`,
`Γ = F(1)`, and `Π = Φ(1) = ΛB′ = −Π_J`. The orthogonal complements are
unaffected — `col(Λ⊥) = col(α⊥)` — and every statement below uses only ranks and
complements, so the sign does not propagate. The BVECM appendix normalises
`α = [I_r ; −β]`, so its `β` is `−B₂`
([ESTUDIO_BVECM_vs_DRVEC.md](ESTUDIO_BVECM_vs_DRVEC.md) §2.1).

**Definition 1 (the parameter set the optimiser sees).** `𝒫` is the set of
`θ = (Λ, B₂, F_i, Θ_j, Σ)` such that `Σ > 0`, `Λ` has rank `r`, the roots of
`|Φ(x)| = 0` are on or outside the unit circle, and the roots of `|Θ(x)| = 0`
are on or outside it. This is what the engine enforces: it rejects roots
strictly **inside**, and in fact admits moving-average eigenvalues up to
`1.00005`, i.e. root moduli down to `0.99995`.

**Definition 2 (the model class).** `𝒞 ⊂ 𝒫` is the set of `θ` for which `{Y_t}`
generated by (1) is I(1) with cointegrating rank **exactly** `r`.

The distinction between `𝒫` and `𝒞` is the subject of this note. §4 shows
`𝒞 ⊊ 𝒫`, that the difference is not a null set the optimiser avoids by luck, and
that everything the program claims about its estimates is proved on `𝒞`.

## 2. The transformation, and what it does not add

**Theorem 1 (Mauricio's transformation) [standard].** Let
`Ȳ_t = (∇Y_{2t}′, W_t′)′` and

`C̄ = [0 I_s ; I_r B₂′]`,  `C̄⁻¹ = [−B₂′ I_r ; I_s 0]`,  `H̄ = [0 0 ; 0 I_r]`,
`Π̄ = [0, Λ]`.

Then (1) is equivalent to the VARMA `Φ*(L)Ȳ_t = Θ*(L)A*_t` with

  `Φ̄₀ = C̄⁻¹`,  `Φ̄₁ = C̄⁻¹H̄ − Π̄ + F₁C̄⁻¹`,
  `Φ̄_i = F_iC̄⁻¹ − F_{i−1}C̄⁻¹H̄` (`2 ≤ i ≤ p−1`),  `Φ̄_p = −F_{p−1}C̄⁻¹H̄`,
  `Φ*_i = C̄Φ̄_i`,  `Θ*_j = C̄Θ_jC̄⁻¹`,  `A*_t = C̄A_t`,  `Σ* = C̄ΣC̄′`.

*Remark.* The map is an algebraic rearrangement: it is a bijection between
parameter values, for fixed `B₂` a similarity on the moving average, and it
adds no restriction and removes none. Verified numerically to `4·10⁻¹⁵` on a
simulated system with a general, non-scalar `Θ`, with three plausible
alternative forms of `Θ*` failing by 0.56 to 2.5
([HOMOLOGATION.md](HOMOLOGATION.md) §4g).

**Corollary 1.1 [new here].** `Θ*(x)` and `Θ(x)` have the same determinantal
roots, and `det Θ*(1) = det Θ(1)`. Hence any invertibility statement about the
transformed system is a statement about `Θ`, and the moving-average pathology of
§4 is visible in both coordinate systems.

*Proof.* `Θ*(x) = C̄Θ(x)C̄⁻¹` for every `x`, a similarity. ∎

**Corollary 1.2 [new here].** An identity cannot create structure. In
particular, appealing to Theorem 1 does not establish that a VEC model with free
`F_i` and free `Θ_j` admits a triangular (WARMA) representation: Theorem 1 maps
each parameter point to exactly one transformed point, and the triangular class
is a proper subset of the image (§5).

## 3. Granger representation for (1)

**Theorem 2 (long-run impact) [standard for the VAR, restated here for (1)].**
Suppose

  (a) `|Θ(x)| ≠ 0` for `|x| < 1`;
  (b) `|Φ(x)| = 0` has exactly `s = M − r` roots at `x = 1` and all others
      outside the unit circle;
  (c) `det(Λ⊥′F(1)B⊥) ≠ 0`.

Then

  **(4)**  `Y_t = C Θ(1) Σ_{u=1}^{t} A_u + ξ_t + ζ`,  with
  `C = B⊥ (Λ⊥′F(1)B⊥)⁻¹ Λ⊥′`,

`{ξ_t}` stationary and `ζ` depending on initial values.

*Proof sketch.* By (b) and (c), `Φ(x)⁻¹` has a simple pole at `x = 1`, so
`Φ(x)⁻¹ = C/(1−x) + H(x)` with `H` analytic on a neighbourhood of the closed
disc, and `C` is the standard Johansen constant, obtained from `Φ(1) = ΛB′` and
`Φ′(1) = −F(1)` by solving `Φ(x)[C/(1−x) + H(x)] = I` at `x = 1`. Substituting
into `Y_t = Φ(L)⁻¹Θ(L)A_t` and using `Θ(L) = Θ(1) + (1−L)Θ̃(L)` gives (4); (a)
makes the remainder stationary. ∎

**Theorem 3 (the rank is what the parameters say it is) [new here in this
parameterisation].** Under (a)–(c), the cointegrating space of `{Y_t}` is
`{b : b′CΘ(1) = 0}`, its dimension is `M − rank(Λ⊥′Θ(1))`, and therefore

  **`{Y_t}` has cointegrating rank exactly `r`  ⟺  `rank(Λ⊥′Θ(1)) = s`,**

that is, `Λ⊥′Θ(1)` has full row rank. Equivalently: the left null space of
`Θ(1)` meets the column space of `Λ⊥` only at zero.

*Proof.* `C = B⊥KΛ⊥′` with `K = (Λ⊥′F(1)B⊥)⁻¹` nonsingular and `B⊥` of full
column rank, so `rank(CΘ(1)) = rank(Λ⊥′Θ(1))`, and the annihilator of the
common trends has dimension `M − rank(CΘ(1))`. The columns of `B` always lie in
it, since `B′B⊥ = 0`; the dimension is `r` exactly when `rank(Λ⊥′Θ(1)) = s`.
For the last sentence: `rank(Λ⊥′Θ(1)) < s` iff there is `c ≠ 0` with
`c′Λ⊥′Θ(1) = 0`, i.e. `Λ⊥c` is a left null vector of `Θ(1)`. ∎

**Corollary 3.1 (a sufficient condition that is easy to check) [new here].** If
`det Θ(1) ≠ 0` then the rank condition of Theorem 3 holds automatically.
Consequently **the whole difficulty lives on the surface `det Θ(1) = 0`**, which
is exactly a unit moving-average root at frequency zero.

*Proof.* `Λ⊥′` has full row rank `s` and `Θ(1)` is nonsingular, so the product
has rank `s`. ∎

**Corollary 3.2 (why the differencing language is right) [new here].** A left
null vector `w` of `Θ(1)` means `w′Θ(L)A_t` has a unit moving-average root, so
`w′∇Y_t` is overdifferenced: `w′Y_t` is stationary. If `w` can be written as
`Λ⊥c` then that stationary combination is **not** in the span of `B`, and the
true rank exceeds `r`. If it cannot, the model still has rank `r` and the unit
root is absorbed by the error-correction term.

*Remark (this is the conjecture that started the investigation, proved).* "A
non-invertible moving average means the series can be integrated back if it was
differenced" is Corollary 3.2. What the corollary adds is the qualifier that
decides the case: it is fatal to the rank only when the direction lies in
`col(Λ⊥)`.

## 4. `𝒞 ⊊ 𝒫`, and the difference is where the optimiser goes

**Theorem 4 (the class is a proper subset of the search set) [new here].**
`det Θ(1) = 0` is permitted by Definition 1, the exact Gaussian likelihood is
finite and continuous there, and points of that surface with
`null(Θ(1)′) ∩ col(Λ⊥) ≠ {0}` are **not** in `𝒞`. Hence the maximiser of the
likelihood over `𝒫` need not lie in `𝒞`.

*Proof.* Definition 1 admits roots on the unit circle, and `det Θ(1) = 0` is a
root at `x = 1`. Non-invertibility **at** the boundary leaves the finite-sample
covariance matrix of `(Ȳ_1, …, Ȳ_n)` nonsingular: a unit moving-average root
makes the spectral density vanish at frequency zero, which is a measure-zero
event for a finite Toeplitz form — the scalar case `(1 − B)a_t` has the
tridiagonal `(2, −1)` covariance matrix, nonsingular for every `n`. So the exact
Gaussian likelihood is finite and continuous up to and including that surface,
and the optimiser has no reason not to visit it. The last claim is Theorem 3. ∎

**Theorem 5 (the pathology is invisible to the checks the engine makes) [new
here].** Let `θ ∈ 𝒫 \ 𝒞` as in Theorem 4. Then `Ȳ_t` is still stationary, so no
test on the roots of `Φ*` detects the failure. The failure is visible **only**
as a unit root of `Θ*`, which Definition 1 permits.

*Proof.* `W_t = B′Y_t` is stationary by construction of the model, and `∇Y_{2t}`
is a difference of an I(1) block, hence stationary; so `Ȳ_t` is stationary and
`Φ*` has all its roots outside the circle. By Corollary 1.1, `det Θ*(1) = det
Θ(1) = 0`. ∎

*This is why the condition has to be computed on `(Λ, B, Θ)` directly, which is
what `drvec` now does at every evaluation and reports beside the operator roots.*

**[empirical] Theorem 5, in the output.** The free Milan fit reports autoregressive
root moduli `1.996, 1.996, ∞, 1.715` — comfortably stationary, so the
transformed system is exactly what the engine wants — beside a smallest
moving-average modulus of `1.00026`. Stationary and on the invertibility
boundary at the same time is precisely the signature Theorem 5 predicts, and
every one of the eight pairs shows it.

**[empirical] What the estimator actually does.** On the eight wheat pairs, at
`p = 2, q = 1, r = 1`, the free maximiser over `𝒫` lands with `|Θ̂(1)|` between
`−7·10⁻⁵` and `4·10⁻⁴` — singular to working precision — and with the null
direction of `Θ̂(1)` aligned with `Λ̂⊥` at cosine `0.946` to `0.9996`. By Theorem
3 that is the direction whose degeneracy destroys the rank; the fitted points
sit on the surface of Theorem 4 and close to the subset of it that leaves `𝒞`.
The square statistic `σ_min(Λ̂⊥′Θ̂(1)B̂⊥)` reads `0.016` to `0.133` there against
`≈ 1` for every admissible specification and for a known truth in simulation
([HOMOLOGATION.md](HOMOLOGATION.md) §4h).

**Corollary 5.1 (what the standard errors mean there) [new here].** Phillips
(1991) optimality, the mixed-normal limit of `B̂₂` and the `χ²` limits of Wald
and likelihood-ratio statistics are all proved **on `𝒞`**. At a maximiser in
`𝒫 \ 𝒞`, or in a neighbourhood of its boundary, none of them is licensed: the
estimate is not an interior point of the parameter set of any I(1) model of rank
`r`. A likelihood-ratio statistic comparing a restricted model in the interior
with an unrestricted one at such a point is not `χ²` on the difference in
parameter counts — which is why the comparison of §4i had to be bootstrapped,
and why the bootstrap put the 5 % critical value at 1.5 to 2.3 times the `χ²`
one.

## 5. The triangular (WARMA) class, and the exact form of the equivalence

**Definition 3 (triangular form).** `Φ_w(B)w_t = Θ_w(B)a_t`,
`Δz_{2t} = γw_{t−1} + Σ_{i=1}^{k} Ψ_i w_{t−i} + η_t`, with `w_t = α′z_t`,
`α = [I_r ; −β]`, `(a_t, η_t)` jointly white noise.

**Theorem 6 (the image of the triangular class) [new here; the BVECM appendix
states the forward direction and asserts the converse].** The VEC representation
of a process in Definition 3 satisfies

  **(5)**  `Γ_i = M_i α′` for every `i` — each short-run matrix has rank ≤ `r`
  and row space contained in `row(α′)`; and

  **(6)**  `Θ̃₁ = [Θ_w  −Θ_wβ′ ; 0  0] = [Θ_w  Θ_wB₂′ ; 0  0]` (using `B₂ = −β`),
  i.e. the differenced block carries no moving average of its own and the cross
  block is determined.

Conversely, a VEC model (1) admits a finite-order triangular representation
**iff** its parameters satisfy (5) and (6). In particular the converse asserted
in the BVECM appendix — that *any* VEC model of rank `r` can be written in
triangular form — is false as stated: a free `Γ_i` has rank up to `M`.

*Proof.* Forward: the appendix's own construction, whose every lag enters
through `w_{t−l} = α′z_{t−l}`, so grouping gives `Γ_i = −Σ_{l>i}M_lα′`; and the
regrouping of the innovations on `A_t = (a_t + β′η_t, η_t)′` gives (6), verified
numerically at `4.4·10⁻¹⁶` against `2.0` for the sign-flipped alternative.
Backward: (5) says every lag term is a function of `α′∇z_{t−i}` alone, which is
what allows the system to be written with `w` as the only dynamic argument; (6)
is the moving-average half of the same statement. If (5) fails for some `i`
there is a direction `v` with `α′v = 0` and `Γ_i v ≠ 0`, so `∇z_t` depends on
`∇z_{t−i}` outside the span of `w`, which no equation of Definition 3 provides. ∎

**Corollary 6.1 [new here].** In transformed coordinates the restrictions of
Theorem 6 are a pattern of zeros, and `B₂` disappears from them:

| restriction on `Θ` | `Θ*` on `Ȳ = [∇Y₂ ; W]` |
|---|---|
| free | free |
| `[T₁₁ T₁₂ ; 0 T₂₂]` | `[[T₂₂, 0],[·, T₁₁]]` — the `∇Y₂` equation keeps a moving average |
| `[T₁₁ T₁₂ ; 0 0]` | `[[0, 0],[·, T₁₁]]` |
| `[T₁₁ T₁₁B₂′ ; 0 0]` | `[[0, 0],[0, T₁₁]]` — diagonal |

*So Definition 3 is exactly `Θ*` diagonal together with `Φ*_k` having its first
`s` block-columns zero, and in those coordinates `B₂` enters the likelihood only
through `W = Y₁ + B₂′Y₂`. That is the reason to estimate the class there, and
the measured consequence is eight gradient convergences out of eight with
multi-start spreads of 0.000 to 4.0 against 0.4 to 18.7
([HOMOLOGATION.md](HOMOLOGATION.md) §4l).*

**Corollary 6.2 (which zero carries the admissibility) [new here].** Under (6),
`Θ(1) = [I − Θ_w  −Θ_wB₂′ ; 0  I]`, block triangular with identity in the lower
block, so `det Θ(1) = det(I − Θ_w) ≠ 0` unless `Θ_w` has a unit eigenvalue. The
degeneracy of Theorem 4 is therefore **impossible in the differenced block** and
possible only in the cointegrated one. Dropping the lower-left zero while
keeping `T₂₂` free does not buy this; dropping `T₂₂` does.

*Measured, and it is why `-matri` changed nothing while `-marow` did: with `T₂₂`
free the optimiser takes it to one, which is `(1 − B)` acting on the already
differenced block ([HOMOLOGATION.md](HOMOLOGATION.md) §4j).*

## 6. The boundary at `r = 0`, and the rank test

**Theorem 7 [new here].** At `Λ = 0`: (i) `Π = ΛB′ = 0` for every `B₂`, so `B₂`
is unidentified; (ii) `Φ(x) = F(x)(1−x)` has `M` unit roots, so `Ȳ_t` contains
`W_t = B′Y_t`, which is then I(1), and the transformed system has an
autoregressive root at exactly one; (iii) the exact likelihood of the
transformed system is therefore undefined at that point.

*Proof.* (i) is immediate. (ii): with `Λ = 0`, (3) gives `Φ(x) = F(x)(1−x)`,
whose determinant vanishes to order `M` at `x = 1`; `W_t` is then a linear
combination of an I(1) vector with no cointegration imposed. (iii): the
stationary VARMA likelihood requires the roots of `|Φ*(x)|` outside the circle. ∎

**Corollary 7.1 [new here].** The null of the sequential rank test — `H₀ : r`
against `H₁ : r+1` — sits on the **boundary** of the alternative's parameter
set, with a nuisance parameter (`B₂`) unidentified under it. Standard `χ²`
asymptotics do not apply, and the tabulated non-standard values are the correct
reference only under the assumptions used to derive them.

*[empirical] Consistent with the measured over-rejection: at `n = 120` the
asymptotic sequential test picks the right rank 68 % of the time and rejects a
true `r` at 30 % against a nominal 5 % ([HOMOLOGATION.md](HOMOLOGATION.md) §2.3).*

## 7. What follows for the program

1. **The admissible set has to be part of the estimation problem, not of the
   commentary.** By Theorems 3–5 the condition is `rank(Λ⊥′Θ(1)) = s`, it is not
   implied by anything the engine checks, and it is violated in the direction the
   fits actually take. `drvec` reports `σ_min(Λ⊥′Θ(1)B⊥)` at every fit and can
   enforce a floor (`-rankadm`); by Corollary 3.1 the simpler sufficient
   condition `det Θ(1) ≠ 0` would also do, and is cheaper to state.

2. **A specification beats a floor.** By Corollary 6.2 the restriction
   `Θ = [T₁₁ T₁₂ ; 0 0]` makes the degeneracy impossible by construction, with
   no constant to choose. That is the theoretical reason to prefer `-marow` and
   `-warma` to `-rankadm` for estimation, and to keep `-rankadm` as the
   diagnostic.

3. **Restrictions belong in transformed coordinates.** Corollary 6.1: there they
   are zeros and `B₂` is absent from them; in VEC coordinates the same
   restriction couples `Θ` to `B₂` and must be rebuilt at every evaluation.

4. **Inference has to be earned.** Corollary 5.1: the mixed-normal and `χ²`
   limits are theorems about `𝒞`. Every likelihood-ratio comparison whose
   unrestricted optimum sits near the boundary needs its distribution simulated,
   which is what `-matest` and `-bootstrap` do.

5. **What is still open.** Whether the restriction (5) on the short-run matrices
   holds for these data is measured only as an indication — five of eight fitted
   `F̂₁` are near rank one, but the row space matches `α′` in one
   ([HOMOLOGATION.md](HOMOLOGATION.md) §4k). Turning that into a test is step 5
   of [SPECIFICATION_PLAN.md](SPECIFICATION_PLAN.md). And no claim is made here
   that the triangular class is *true* for any of these series: what the theory
   gives is which parameter points are admissible, and what the measurements add
   is that outside the inadmissible neighbourhood every route agrees about `B₂`.
